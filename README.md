## What the project is about
This project demonstrates the fundamentals of JavaScript, including variables, data types, type conversion, type coercion, the `typeof` operator and floating-point precision. It also explores common JavaScript behaviours and edge cases, while applying clean coding practices such as using `const` and `let`, meaningful variable names, explicit type conversions, comments, and template literals.



## what I have learnt while doing it
During this project, I learned how JavaScript handles different data types, variables, type conversion and type coercion. I learned the difference between implicit and explicit conversion, how to use tools such as `Number()`, `parseInt()`, `parseFloat()`, `Boolean()`, `String()` and `typeof`, and how to handle special values like `NaN`, `null`, and `undefined`. I also learned about floating-point precision and how `Number.EPSILON` can be used for safer comparisons. Most importantly, I learned how to write cleaner, more reliable JavaScript code using `const` and `let`, meaningful variable names, explicit conversions and comments.
